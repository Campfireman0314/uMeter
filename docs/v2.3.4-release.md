# uMeter v2.3.4 Release Notes

## Summary

v2.3.4 closes the draggable detail-graph polish pass with steadier module reordering, inactive hidden graph rendering, clearer resize handles, alias-edit hover hints, and a compact fixed-height collision analyzer.

## Highlights

- Collision analyzer modules are restored to their original compact fixed height and no longer show a stretch handle.
- Detail module drop indicators fade in place instead of animating layout height, avoiding graph block twitch near neighboring rims.
- Hidden waveform, spectrograph, and loudness-clock modules now gate tick-driven rendering work while inactive.
- Detail resize grips use the themed handle template even when graph-specific visibility styles are applied.
- Source, inline detail, and pop-up detail title banners now show `Double click to edit alias` on hover.
- Product metadata and packaging defaults now target `2.3.4`.
