# v2.0.1 Release Notes

`v2.0.1` is an appearance, compatibility, and performance polish release for `uMeter`.

## Highlights

- Adds a title-bar theme chooser with Midnight, Milk White, Forest Green, and Pink Dream.
- Persists the selected theme across restarts in `%APPDATA%\uMeter\settings.json`.
- Themes the stereo image graph, waveform roll, spectrum roll, and correlation meter.
- Tunes Milk White for warmer milk/ivory signal and spectrum plotting.
- Adds Eco mode to reduce UI refresh and spectrum analysis cost on lower-end machines.
- Relaxes process-loopback attempts to Windows 10 19041+ while warning that builds below documented Windows 11 support remain experimental.

## Compatibility Notice

Windows builds below 19041 cannot use process-loopback capture. Builds 19041 through 20347 can attempt it, but the app reports a startup warning because Microsoft's documented support starts at Windows 11 build 20348.
