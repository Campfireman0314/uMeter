# v1.1.0 Release Notes

Pinned on 2026-06-17.

`v1.1.0` is the second public polish release. It focuses on making the advanced detail analyzers easier to inspect without changing the core WASAPI/process-loopback architecture.

## Highlights

- Waveform and spectrum displays can now switch between summed overall display and per-channel plots through compact gear menus.
- Waveform and spectrum panels open at a usable full-scale height and enforce practical minimum plot heights.
- Waveform and spectrum roll views support vertical drag-panning, mouse-wheel vertical zoom around the cursor, and double-click reset.
- Pan and zoom are clamped to valid data ranges: waveform stays inside the signal domain, and spectrum stays within 20 Hz to 22 kHz.
- The combined waveform/spectrum divider now stretches the waveform side without changing the current spectrum height.
- Stereo image settings include trace persistence, a user-facing control for dot history/intensity.
- Stereo image scale buttons now use the same gear-icon language as the roll-view settings.
- Scrollbars use the app's dark full-height rail style; the previous capped vertical scrollbar behavior is gone.

## Notes For Next Work

- Settings are still not persisted across app restarts.
- Multiple detail windows watching the same process still share one analyzer stream, so the latest true-peak oversampling choice for that process wins.
- DSP behavior has synthetic test coverage but is still not certified against official loudness reference vectors.
- The installer remains unsigned, so Windows SmartScreen can warn on first use.
