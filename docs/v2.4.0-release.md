# uMeter v2.4.0 Release Notes

Released: 2026-08-05

v2.4.0 adds localized workflows and reliable ways for a sender plugin or Windows login to start the desktop host.

## Localization

- The desktop app supports English, Simplified Chinese, Japanese, and Russian.
- Windows display language is used automatically, with English fallback for unsupported locales.
- Global Settings provides a persisted manual language choice and updates open desktop windows immediately.
- Static controls, detail banners, hover explanations, meter mode menus, source labels, event filters, tray actions, and primary status text are localized.
- The VST3 sender reads the same persisted language preference and otherwise follows the OS display language.
- The installer follows the OS language for its layout, progress, elevation, success, and failure messages.
- Global Settings and installer layouts are wider and use wrapping where localized text can grow.

## Host Startup

- Global Settings can register uMeter under the current user's Windows Run key.
- Automatic Windows or sender launches can start directly in the notification area through `--background`.
- Notification-area startup remains independently selectable when both automatic launch sources are disabled.
- A separate option lets loaded VST3 senders invoke uMeter when no receiver is acknowledging.
- Sender-driven launch runs from a JUCE message-thread timer and never from the audio callback.
- The VST3 editor includes a manual `Start uMeter` button with localized success and error feedback.
- Manual launches remain visible. Custom install paths resolve through the per-user uninstall registry entry, with a per-user install fallback.

## Reliability and Terminology

- VST monitor pop-ups can be opened from the tray while uMeter has started hidden; a never-shown main window is no longer assigned as their WPF owner.
- True Peak is written in full in every supported language instead of using the `TP` abbreviation.
- The 2x, 4x, and 8x choices describe oversampling multipliers with localized terminology.
- Diagram-setting flyouts localize their detached popup labels and explanations.
- Detail source status, unavailable readouts, true-peak maximum text, and the stereo correlation label are localized.
- Detail source identities, active/inactive WASAPI states, spectrum ranges, and loudness-clock ranges are localized and refresh with the selected language.
- App rows use process-loopback PCM to confirm actual render output where supported, so capture-only apps such as OBS stay hidden unless they produce monitoring or other rendered audio.
