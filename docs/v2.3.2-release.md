# uMeter v2.3.2 Release Notes

## Summary

v2.3.2 completes the 2.3.x rendering polish pass with lower-drag waveform rendering, viewport-aware spectrograph resolution, unified detail title editing, and a configurable loudness clock.

## Highlights

- Waveform rendering uses viewport-bounded display budgets to reduce long-session UI cost.
- Spectrograph rendering adapts resolution to viewport size and avoids wrap-stripe artifacts.
- Inline and pop-up detail titles now use the same editor behavior as source rows.
- Loudness clock supports configurable range, warning threshold, cycle duration, fan fill, scan line, and over-maximum danger coloring.
- Loudness clock fan segments bridge the cycle origin so wrap points do not leave a visible slit.
- Product metadata and packaging defaults now target `2.3.2`.
