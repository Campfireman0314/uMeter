# uMeter v2.3.0 Release Notes

Date: 2026-06-26

## Highlights

- Keeps sources continuous through DAW sample-rate changes, sender format restarts, temporary WASAPI handle loss, and analyzer warmup frames.
- Sharpens spectrograph rendering by removing hidden vertical smoothing/gap filling and using raw PCM for spectrum FFT input.
- Allows only one uMeter desktop instance per user session; repeated launches activate the existing instance.
- Merges source alias editing into the global row title with double-click editing.
- Adds per-source hide/restore, a global `Show hidden` toggle, and persistent source ordering.

## Validation

- Managed unit tests passed with 231 tests.
- Solution build passed.
- JUCE VST3 Debug CTest suite passed.

## Known Boundaries

- Spectrograph buckets still use center-sampled Mel positions with a Hann window; the renderer no longer exaggerates leakage, but physical window leakage remains visible.
- Source ordering persists by stable source key. New sources without explicit order still fall back to kind/name/key sorting.
- The installer remains unsigned, so Windows SmartScreen may warn on first launch.
