# v2.2.7 Release Notes

`v2.2.7` is a detail-window and Milk White graph-contrast polish release for `uMeter`.

## Highlights

- Pop-up detail windows no longer inherit the global window's `Always on top` behavior.
- Pop-up detail windows still open near the main window when possible, with a center-screen fallback from tray/hidden-main usage.
- Milk White graph colors are more legible across waveform, stereo image, spectrum, and collision views.
- Milk White plot contrast is protected by a regression test.
