# v2.2.5 Release Notes

`v2.2.5` is a mix-event and VST3 sender-status patch release for `uMeter`.

## Highlights

- Adds conservative `Possible overlap` Recent Events from enabled detail collision analysis.
- Adds receiver acknowledgement packets to the local loopback protocol.
- Shows live receiver connection status inside the JUCE `uMeter Sender` VST3 editor.
- Polishes the VST3 sender status indicator so it remains circular and visually balanced.
- Fixes reset behavior that could leave waveform and spectrograph rolls waiting on stale plot-frame versions.

## Known Boundaries

- The VST3 sender still uses the inspectable JSON/base64 UDP protocol on fixed port `38173`.
- Sender status is connection feedback only; it does not alter the audio pass-through path.
- AAX distribution still requires Avid/PACE signing, validation, and Pro Tools smoke testing.
