# uMeter v2.2.8 Release Notes

Date: 2026-06-21

## Highlights

- Adds optional RfRapid native acceleration for true-peak reconstruction.
- Keeps the managed true-peak estimator as automatic fallback when `DesktopLoudnessMeter.Native.dll` is unavailable.
- Adds a lightweight benchmark harness for DSP hot-path comparisons.
- Preserves the existing 100 ms rolling true-peak window and oversampled waveform/spectrum display samples.

## Benchmark

Local 30 s stereo 48 kHz benchmark:

- Managed 8x true peak: about `1.95 Mframes/s`.
- Native RfRapid 8x true peak: about `4.44 Mframes/s`.
- Peak output matched between managed and native paths.
