# v2.2.3 Release Notes

`v2.2.3` is a frequency-collision and source-workspace polish patch release for `uMeter`.

## Highlights

- Adds persistent source aliases and per-source detail analyzer preferences.
- Refines frequency collision detection around prominent spectral features instead of raw level similarity.
- Replaces the collision analyzer `Absolute` threshold with a clearer `Level floor` gate.
- Adds a tunable `Prominence` gate and renames `Relative` to `Match tolerance`.
- Adds double-click numeric entry to the collision analyzer single-value sliders.

## Collision Analyzer

The collision analyzer now requires both compared sources to clear the selected level floor and show local spectral prominence before a band is highlighted. This avoids treating flat broadband content, such as white noise, as a full-band musical collision.

The collision option panel now exposes:

- `Level floor` for ignoring weak bins.
- `Prominence` for requiring locally meaningful spectral features.
- `Match tolerance` for controlling how close two prominent bins must be.

`Prominence` defaults to `6 dB`. Setting it to `0 dB` relaxes the prominence gate for comparison or broad-source inspection.

## Source Workspace

Source aliases and detail analyzer preferences are now stored in the user workspace. Inline and pop-up detail views remember waveform, spectrum, collision, stereo image, collision source, threshold, and display-range choices per source key.
