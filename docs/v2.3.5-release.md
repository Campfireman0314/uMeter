# uMeter v2.3.5 Release Notes

Released: 2026-08-05

v2.3.5 is a focused reliability and detail-metering patch.

## Fixed

- The VST3 sender remains discoverable when a host releases audio resources during hibernation or graph deactivation instead of waiting for the host to restart it.
- Senders without recent receiver acknowledgements renew their localhost UDP transport on a bounded interval and continue registration from the same stable source handle.
- Inline and pop-up module dragging captures the pointer from button-down and observes preview drag events across graph children.
- Reorder placement is deterministic: upward drags insert before a target and downward drags insert after it, including reliable insertion at the top.
- Closing the main panel closes its detail popups and exits the application.
- Each detailed numeric meter independently switches between Overall, Mid, and Side measurements while global rows remain Overall.
- Each selector is a compact borderless triangle to the left of the title; `(I)`, `(M)`, and `(S)` title markers expose the selected mode without reducing meter width.
- Detailed meters and diagrams provide hover explanations controlled by a persisted Global Settings option.
- Explanations activate only over meter titles and diagram banners, disappear as soon as the pointer moves, and use lightweight in-window adorners to avoid interrupting live rendering.
