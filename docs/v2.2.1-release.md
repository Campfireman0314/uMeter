# v2.2.1 Release Notes

`v2.2.1` is a crash-fix patch release for `uMeter`.

## Highlights

- Fixes a long-run spectrum rendering crash caused by transient WPF `WriteableBitmap` read/write lock conflicts.
- Extends spectrograph level inspection to `-200 to 0 dB`, with the visible default set to `-120 to 0 dB`.
- Keeps the v2.2.0 frequency collision analyzer, smoother graph update path, spectrograph display range slider, and AAX sender groundwork.

## Crash Fix

The observed crash was:

```text
System.Runtime.InteropServices.COMException (0x88982F0D)
WriteableBitmap.WritePixels
DesktopLoudnessMeter.App.Controls.SpectrumRollView.AppendSpectrumColumn
```

`SpectrumRollView` now treats this WPF bitmap lock conflict as a recoverable rendering condition. If a bitmap write cannot complete immediately, the control marks the spectrum history dirty and retries a full bitmap refresh later on the dispatcher instead of terminating the app.
