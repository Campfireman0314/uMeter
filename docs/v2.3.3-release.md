# uMeter v2.3.3 Release Notes

## Summary

v2.3.3 closes the UI reliability and detail-layout preset pass with immediate theme refreshes, a more reliable tray menu, portable detail-layout JSON presets, and loudness-clock time/hover interaction polish.

## Highlights

- Slider and other resource-backed controls refresh immediately when the app theme changes, including controls inside open popups.
- Tray right-click handling now uses the native Windows Forms notify-icon context menu path and rebuilds entries as the menu opens.
- Inline and pop-up detail panels can save and load visualization layout/settings as JSON presets.
- Global settings can point to a default detail-layout preset file, validates it, and falls back to built-in defaults if the file is missing or invalid.
- Loudness clock adds time scale markers and a hover readout blob for cycle time and LUFS value inspection.
- Product metadata and packaging defaults now target `2.3.3`.
