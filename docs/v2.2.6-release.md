# v2.2.6 Release Notes

`v2.2.6` is a rendering architecture and platform-strategy patch release for `uMeter`.

## Highlights

- Adds shared deferred render scheduling for waveform and spectrum controls.
- Adds shared plot background-cache invalidation for waveform, spectrum, and collision analyzer controls.
- Moves main graph controls onto named plot color roles instead of repeated resource-key strings.
- Adds rendering architecture notes for future graph cleanup.
- Adds platform strategy notes for future AAX, macOS/AU, and iOS planning.

## Known Boundaries

- This release does not add a new platform implementation.
- Rendering cleanup preserves the existing visual behavior; visual regression screenshots are still recommended before larger plot-layout changes.
- AAX distribution still requires Avid/PACE signing, validation, and Pro Tools smoke testing.
