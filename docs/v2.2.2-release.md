# v2.2.2 Release Notes

`v2.2.2` is a spectrograph visual-polish patch release for `uMeter`.

## Highlights

- Keeps the `-200 to 0 dB` spectrograph inspection range, defaulting to `-120 to 0 dB`.
- Adds double-click numeric entry to the spectrograph dB range selector for direct min/max edits.
- Softens low-energy spectrograph rendering so the roll view stays continuous and avoids harsh black-hole artifacts.
- Preserves raw spectrum history values; the soft floor and neighboring-bin smoothing are render-only.

## Spectrograph Polish

The spectrograph now separates stored analysis values from display color mapping. Raw bucket history remains unchanged, while the pixel renderer applies a soft visual floor below the selected display minimum and light vertical smoothing between adjacent frequency buckets.

This keeps the graph readable at very deep ranges without turning low-level energy into hard black gaps.
