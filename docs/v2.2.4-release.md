# v2.2.4 Release Notes

`v2.2.4` is a Recent Events and global event-settings patch release for `uMeter`.

## Highlights

- Adds a bounded Recent Events strip to the global view.
- Records source appeared/disappeared, true-peak max, and loudness-jump events.
- Adds event display filters for all, source, peak, and loudness event types.
- Keeps the Recent Events result area fixed-height so the source list does not jump.
- Adds a global settings window for maximum retained events and future event output folder selection.

## Recent Events

The global view now has a compact Recent Events strip that answers the practical question "what just happened?" without turning the app into a heavy timeline. It keeps a bounded in-memory event history and exposes filters for source lifecycle, true-peak, and loudness-jump events.

The maximum retained event count defaults to `6` and can be changed from Global Settings. Values are clamped to `1..200`.

## Global Settings

The title-bar gear now opens a modeless Global Settings window. It currently exposes:

- `Maximum event entries`
- `Event output folder`

The output folder is persisted now so the next event/snapshot export work has a user-facing destination already in place.
