# v2.0.0 Release Notes

`v2.0.0` is the VST3-compatible public release and the first release under the `uMeter` name by Campfireman Studio.

## Release Theme

This release promotes the plugin-source architecture from a working checkpoint into the packaged product. `uMeter` can monitor normal WASAPI app/session audio and DAW/plugin audio routed through the bundled JUCE VST3 sender.

## Product Identity

- Product name: `uMeter`
- Author/company: `Campfireman Studio`
- Desktop executable: `uMeter.exe`
- Setup executable: `uMeter.Setup.exe`
- VST3 plugin: `uMeter Sender.vst3`
- Log path: `%LOCALAPPDATA%\uMeter\umeter.log`

## Installer

The installer now exposes:

- App install folder, defaulting to `%LOCALAPPDATA%\Programs\uMeter`.
- Desktop shortcut option.
- Start Menu shortcut option.
- VST3 sender install option.
- VST3 install folder, defaulting to `C:\Program Files\VSTPlugins`.
- Forced standard VST3 mirror folder: `C:\Program Files\Common Files\VST3`.

Installing the VST3 sender into Program Files may require administrator permission. The installer can relaunch elevated when the selected VST path needs it.

Uninstall cleanup also relaunches elevated when the app or VST3 location is protected, so the copied plugin bundles can be removed cleanly. It removes `uMeter Sender.vst3` from both the selected VST folder and the standard VST3 mirror folder.

Legacy cleanup removes old `Desktop Loudness Meter Sender.vst3` bundles from the selected VST path and standard VST3 scan folders.

Generated artifacts:

```text
artifacts\uMeter.Setup.exe
artifacts\uMeter-Setup-2.0.0.exe
```

Quiet examples:

```powershell
.\artifacts\uMeter.Setup.exe --quiet --install-dir "$env:LOCALAPPDATA\Programs\uMeter" --vst-dir "C:\Program Files\VSTPlugins"
.\artifacts\uMeter.Setup.exe --quiet --install-dir "D:\Tools\uMeter" --no-shortcuts --no-vst
```

## Included VST3 Support

- Pass-through JUCE VST3 audio effect.
- Stable per-instance sender handle.
- Host-based default names such as `Cubase 7F3A`.
- Live source-name updates while editing the plugin text field.
- Temporary mute button.
- Repeated registration packets so the desktop app can discover senders that started before the app.
- Clean unload behavior: main rows disappear, while open detail windows show `Instance not found`.

## Known Limits

- AAX is not implemented in this release.
- The VST3 sender still uses the inspectable v1 JSON/base64 UDP loopback protocol on fixed port `38173`.
- The installer is unsigned, so Windows SmartScreen may warn on first launch.
- Persisted user settings are still a future slice.
