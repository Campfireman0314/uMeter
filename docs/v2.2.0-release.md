# v2.2.0 Release Notes

`v2.2.0` is a frequency-collision, rendering responsiveness, and release-structure polish release for `uMeter`.

## Highlights

- Adds a frequency collision analyzer in detail views for comparing the focused source against another source or `Global`.
- Provides absolute dB and relative similarity thresholds, plus a themed horizontal collision band from 20 Hz to 22 kHz.
- Adds cursor frequency marking for the collision analyzer.
- Adds a spectrograph display range control with a themed two-thumb dB slider, defaulting to `-96 to 0 dB`.
- Improves waveform, spectrum, and collision analyzer smoothness by driving plot refresh from analyzer-frame ticks rather than collection reference changes.
- Adds first AAX sender project groundwork using the shared JUCE sender implementation.
- Improves installer feedback after successful elevated installs.
