## 2026-06-30 native protocol ingest implementation

- Implemented `2026-06-30-native-protocol-ingest-core`: receiver-side Protocol v1 JSON decode and ack payload generation moved into native `DlmLoopbackProtocol`, with managed `NativeLoopbackProtocol` mapping flat native packets back to `LocalLoopbackPacket`. Host `LocalLoopbackUdpReceiver` now keeps UDP socket and loopback remote filtering glue while delegating protocol decode/ack to native core; `DlmSourceIngestCore` remains the typed source lifecycle/analyzer state boundary.

## 2026-06-30 native host source-list projection implementation

- Implemented `2026-06-30-native-host-source-list-projection-core`: Host source-list projection metadata now delegates to native `DlmHostSourceProjection` through managed `NativeHostSourceProjection`. The native core covers generic WASAPI/local/plugin rows for hidden filtering, ordering, duplicate title disambiguation, identity/title text, workspace row defaults, and selected-source visibility. Host still owns recent events, detail/collision snapshots, settings persistence, command mutation, and metric passthrough.
