# 2026-07 AiKnowledge Log

## 2026-07-01 - WebView native UI parity redraw

- Change `2026-07-01-webview-native-ui-parity-redraw` redrew the Web `AppShell` from a three-column dashboard into a compact native-client-style shell.
- The Web shell now exposes app chrome, status/global controls, source list, selected-source detail readouts, stacked chart modules, and recent/settings secondary surfaces while preserving existing HostBridge command wiring.
- The change intentionally did not add fake Web controls for native-only source management actions that do not yet have HostBridge command support.

## 2026-07-01 - completion audit refresh

- Change `2026-07-01-completion-audit-refresh` refreshed the overall WebView UI + C++ Core completion matrix and still returned `not_complete`.
- Old completion-audit gaps for `web-settings-workflow-parity` and native Protocol v1 receiver decode/ack are now closed by archived follow-up changes; they should not be repeated as current blockers.
- Current blockers are Host glue-only reduction, native-owned aggregate `HostSnapshot`/core state projection, and macOS WKWebView runtime transport/build evidence. Web settings/theme/charts are improved, but final WPF-oracle workflow parity still needs explicit scope verification before WPF retirement is complete.

## 2026-07-01 - native host recent events core

- Change `2026-07-01-native-host-recent-events-core` moved Host/Web source appeared recent-event lifecycle/history from `DesktopMeterHostController` C# collections into native `DlmHostRecentEvents`.
- The native core tracks unfiltered live source keys separately from visible projected rows, so hidden-live then visible remains a visibility change, not a source appearance.
- WPF local recent events are intentionally unchanged; `MainViewModel` still owns source disappeared, true peak, loudness, collision, and recent-event filtering workflows.
- Remaining Host-owned follow-ups include selected detail projection, settings projection/persistence, frequency collision projection, command mutation, platform time text, and native-wrapper orchestration.
