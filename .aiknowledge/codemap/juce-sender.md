# JUCE Sender

## Responsibility
Owns the VST3 sender side of Protocol v1 local loopback: worker-thread lifecycle, Protocol v1 JSON packet emission, register/heartbeat/audio/rename/close lifecycle, realtime audio queueing, receiver ack polling, dropped packet accounting, and sender connection state. JUCE remains DAW-side sender; it does not own host receiver routing or native source ingest state.

Receiver-side Protocol v1 decode and ack payload generation now live in native `DlmLoopbackProtocol`; this does not change JUCE/SenderKit sender responsibilities or packet wire shape.

## Key Files

| File | Role |
|------|------|
| src/DesktopLoudnessMeter.JucePlugin/Source/LoopbackSender.cpp | Sender start/stop/restart behavior, UDP worker loop, packet emission, ack polling, and close-suppression state |
| src/DesktopLoudnessMeter.JucePlugin/Source/LoopbackSender.h | Sender state, atomics, queue ownership, and worker declarations |
| src/DesktopLoudnessMeter.JucePlugin/Source/LoopbackProtocol.h | Protocol v1 version, packet type, field name and source kind vocabulary constants plus encode/decode declarations |
| src/DesktopLoudnessMeter.JucePlugin/Source/LoopbackProtocol.cpp | Protocol v1 JSON packet encoding, little-endian float32 base64 audio payload, and ack matching |
| src/DesktopLoudnessMeter.JucePlugin/Tests/LoopbackProtocolTests.cpp | Protocol v1 wire-shape, audio payload and ack rejection contract coverage |
| src/DesktopLoudnessMeter.JucePlugin/Tests/LoopbackSenderTests.cpp | Lifecycle packets, ack state, and same-handle restart packet-order coverage |
| src/DesktopLoudnessMeter.JucePlugin/CMakeLists.txt | VST3 project version and build definition |

## Implicit Constraints
- Same-handle restarts during host sample-rate/channel changes must emit a new register without an intervening close.
- Explicit stop, plugin unload, and destruction still emit close when the worker was active.
- Shutdown-mode flags must be published before waking or stopping the worker thread.
- Protocol v1 field names and packet type strings must remain aligned with `DesktopLoudnessMeter.Protocol.LocalLoopbackProtocol`; contract tests should characterize wire shape before refactors.
- `LoopbackProtocol::isAckForHandle` must reject wrong protocol, wrong type, wrong handle, invalid JSON, null data and empty data.
- Host ack payloads are now generated by native `DlmLoopbackProtocol`; JUCE ack matching expectations remain the compatibility oracle for sender connection state.
- Current local environment may lack `cmake` / `JUCE_DIR`; do not claim JUCE binary tests passed without a real runner output.
